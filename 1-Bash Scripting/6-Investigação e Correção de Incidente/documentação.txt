Aula 4:
find / -name "billing": procurar no caso no repositorio / tudo o que contem "billing"
find / -name "billing" 2>/dev/null : remove tudo o que deu erro de permission denied
cd: change diretorio
ls: listar os ficheiros na pasta
ls -la: mais conteudo 
primeira coluna:
d -> diretorio

head app.log: mostra do ficheiro app.log as 10 primeiras linhas 
tail app.log: mostra do ficheiro app.log as 10 ultimas linhas 
tail -f app.log: abrir os logs em tempo real
touch file.txt: criar arquivos
cat file.txt: ver conteudo
nano file.txt: editar o conteudo do ficheiro

tail app.log | grep "ERROR" > somente_erros.txt 
cp file path que quer colar: copiar ficheiro para uma path

ls srv/app: ver o conteudo de uma pasta especifica

mv somente_erros.txt  /srv/app: mover para um caminho especifico
mv teste.txt lixo.txt: renomear o ficheiro

aula 7: permissoes

Print de explicaçoes de permissoes em linux


4 - (R) ler
2 - (W) escrever
1 - (X) execuçao
0 - sem permissoes

Imaginamos que uma pessoa so pode ler, escrever e executar, fica 4 + 2 +1 -> logo chmod 777 billing-config.yml


fazendo o exercicio: 
dono  RW-  --> 6
grupo R--  --> 4
Outros R-- --> 4
